# Kielipuro

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the owner's setup request. Buildless HTML/CSS/JavaScript and a Cloudflare Worker, with D1 for Slack delivery receipts and GitHub Actions for feedback monitoring. npm and pinned Wrangler follow nearby MyBike/Cloudflare conventions.

## Users
Finnish-speaking beginners learning Japanese first. Sampsa is an early tester with moderate Japanese and experience in several languages. His feedback belongs in the same backlog; no separate advanced course is assumed.

## Product Purpose
An encouraging language-learning app built around small practice interactions. This release proves setup, deployment and the feedback loop.

## Capabilities and Constraints
Finnish interface, one explicitly labelled interaction example, browser-local completion state, GitHub feedback, prepared Slack integration. Lesson content, teaching method and course scope are deliberately undecided. No curriculum, real account system or learning-performance claims.

## Brand Commitments
Original name and geometric stream mark. Duolingo inspires approachable practice, not branding or copied assets. Kielipuro is the implementation's recommended working name; domain purchase requires explicit owner approval.

## Product Principles
- Make the first interaction understandable in Finnish.
- Treat experience as feedback context, not a separate course.
- Keep submissions reviewable and require owner approval before implementation.
- Report connection and learning state honestly.
