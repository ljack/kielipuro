# Kielipuro design

A quiet practice notebook with a flowing, original three-line stream mark. Warm paper (#faf8f1), ink (#203b36), deep teal (#176b5b), soft mint (#e4eee5) and ochre (#e7c26b). Open space separates tasks; subtle rules structure supporting information. No mascot, borrowed branding, generated curriculum or decorative Japanese emblems.

The app is an Operate surface: one practice action, honest completion, then a useful feedback form. A serif headline gives the notebook character; controls and body use the native sans stack. Japanese uses the user's Japanese system fonts. System fonts are a deliberate setup-first tradeoff: no external font or tracking requests.

Two-column desktop workspace becomes one column below 760px. 44px minimum controls, visible focus, text plus icons for state, no hover-only information. Practice reveals one answer panel; reduced-motion disables transitions. Feedback stays on the page. No network submission occurs before the user chooses GitHub and submits there.
